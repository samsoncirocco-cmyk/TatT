# The Match step is the smart-match → swipe chain; /matches folds into /artists

Launch-scope triage grill, 2026-07-27. Two roads ran from a finished design to
booking: the deck chain (`/smart-match` intake → `/swipe` card deck, threading
`designSessionId` all the way into the Book CTA) and a parallel results list
(`/matches`) hitting the same semantic-match API with its own design handoff.
Two roads split analytics, split polish, and make a visitor wonder which one is
real.

The deck chain is the funnel's Match step: it is the mobile-native experience,
it carries the design session through to booking, and swiping doubles as
taste-signal collection for the matching algorithm (an explicit goal in the
original pitch deck). `/matches` folds into the `/artists` directory, which
remains the single browse/compare list surface.
