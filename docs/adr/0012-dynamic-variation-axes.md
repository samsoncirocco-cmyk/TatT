# Reveal variations diverge along dynamically-picked axes from a fixed pool

Each reveal's four designs diverge along two axes the bot picks per session from a curated fixed pool (bold↔fine, color↔blackwork, literal↔abstract, minimal↔ornate), targeting whatever intake left most ambiguous — burning a slot on an already-answered axis is noise with compute cost. The bot must log which axes it picked and why; silent selection is not allowed, so ambiguity detection stays auditable.

## Consequences

When intake is specific enough to resolve every axis, style locks and the four slots become compositional interpretations (pose, framing, negative space) — the reveal's job shifts from questionnaire to confidence proof. Four options are kept even then: the choice feeling earned is part of the conversion mechanic, and compositional choice still carries placement-relevant signal.
